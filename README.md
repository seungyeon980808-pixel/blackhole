# 블랙홀 (Blackhole)

> 내 정보가 모두 빨려 들어가는 곳.

생각나는 대로 던져 넣으면 알아서 일정·할 일·기억으로 정리해 주는 개인 비서입니다.
문장, 음성, 사진, PDF, 붙여 넣은 카톡 — 무엇이든 블랙홀에 넣으면 빨려 들어가 달력에 자리를 잡고,
나중에 「9반 진도 어디까지 했지?」처럼 물으면 쌓인 기록에서 찾아 정리해 답합니다.

교사가 학교에서 매일 쓰면서 만든 앱이라 교시·점심·퇴근 같은 학교 시간을 알아듣습니다.

## 할 수 있는 것

- **넣기**: 「내일 3교시 끝나고 수행평가 안내문 돌리기」 → 할 일, 오늘 11:25까지, 알림 10:55
- **바꾸기**: 「치과 3시에서 4시로 바뀜」 「학부모 상담 취소」 「출장 신청 다 했어요」 → 있는 일정을 옮기고·지우고·체크
- **묻기**: 「진도 끝난 반 정리해줘」 → 최근 기록을 찾아 반별로 정리, 근거 기록을 함께 보여 줌 (「?」로 시작하면 무조건 질문)
- **설정도 말로**: 「알람은 2분 전에 울리게」 「퇴근 4시 40분으로」 → 바로 바꾸고 「되돌리기」
- 월·주·일 달력, 우선순위, 기억(메모) 모음, 화면 전체 알람, A4 출력
- 휴대폰(안드로이드)과 같은 달력을 나눠 씀: 휴대폰에서 말하거나 적어 보내면 Mac이 정리

## 쓰는 AI와 비용

Mac 앱이 Anthropic의 **Claude Haiku 5.5** API를 부릅니다. 키는 각자 발급해 앱 설정에 붙여 넣으며, macOS 키체인에만 저장됩니다.

- 간단한 문장은 AI 없이 규칙으로 처리(0원), 같은 요청은 다시 부르지 않음
- 넣기 한 번 약 0.2원, 질문 한 번 약 1.5원 (2026년 10월 실제 사용 기준)
- 월 예산을 정하면 넘을 때 AI를 멈추고 규칙 초안만 씀

## 설치 (Mac)

macOS 12 이상, Apple Silicon 기준으로 만들고 있습니다.

1. [Releases](../../releases)에서 `Blackhole-<버전>-mac.zip`을 받아 풀고 `Blackhole.app`을 「응용 프로그램」에 넣습니다.
2. 개발자 서명·공증을 하지 않은 앱이라 처음 한 번은 **오른쪽 클릭 → 열기**로 엽니다.
3. 설정 → AI에서 [Anthropic 콘솔](https://console.anthropic.com/)에서 만든 API 키를 붙여 넣습니다.
4. 설정 → 학교 시간에서 출퇴근·점심·교시표를 내 학교에 맞춥니다(처음 값은 만든 사람의 학교).

직접 빌드하려면 `docs/development.md`를 보세요. 한 줄 요약:

```sh
cd desktop && npm ci && npm run tauri build -- --bundles app
```

배포용 zip은 `bash desktop/scripts/package-mac.sh`로 만듭니다(`build/release/`).

## 휴대폰 (안드로이드)

휴대폰 앱은 구글 드라이브의 「블랙홀」 폴더를 통해 Mac과 주고받습니다. 구글 로그인이 각자의 Google Cloud 설정(OAuth 클라이언트)에 묶여 있어서
**미리 만든 APK를 나눠 줄 수 없고, 각자 빌드해야 합니다.** 필요한 값은 `tools/private.env.example`을 보고 저장소 밖
`~/.config/blackhole/private.env`에 채운 뒤 `build.sh`로 빌드합니다(자세히: `docs/development.md`).
휴대폰 없이 Mac 앱만 써도 됩니다.

## 내 정보는 어디에

- 달력·기억: 이 Mac의 `~/Library/Application Support/com.malhaedwo.blackhole.desktop/` (휴대폰 공유를 켜면 내 구글 드라이브 「블랙홀/」에 사본)
- API 키·비밀번호류: macOS 키체인에만. 비밀번호처럼 보이는 글은 AI에 보내지 않음
- AI에 가는 것: 넣은 글, 질문할 때 찾은 기록 줄. 그 밖의 서버는 쓰지 않음
- 이 저장소에는 개인 자료·키·토큰·서명키를 넣지 않음 (`SECURITY.md`)

## Ya에서 이어진 앱

블랙홀은 새로 만든 앱이 아니라 **Ya(야)를 이어 만든 다음 판**입니다. 같은 저장소, 같은 휴대폰 앱입니다.

| | 말해둬 → Ya (~2026년 9월, 0.8.x) | 블랙홀 (2026년 10월~) |
|---|---|---|
| 기기 | 안드로이드 휴대폰 하나 | Mac 앱 + 안드로이드 휴대폰 |
| 넣는 법 | 음량 버튼을 누르고 말하기(PTT) | 말하기·적기·사진·PDF·붙여 넣기, 무엇이든 |
| 정리 | 승인함에서 확인하고 승인해야 일정이 됨 | 초안이 바로 달력에, AI가 다듬음(확인할 것만 따로 묻기) |
| 보관 | 구글 시트·드라이브 | 내 Mac + 구글 드라이브 「블랙홀/」 |
| 찾기 | — | 쌓인 기록에서 질문에 답하기 |

Ya의 휴대폰 앱 위에 그대로 덮어 설치할 수 있게 안드로이드 패키지 이름(`com.malhaedwo.pttprobe`)과 서명 같은 내부 식별자는 옛 이름을 그대로 둡니다.
Ya 시절 기록은 이 저장소의 `main` 갈래 역사에 남아 있습니다.

## 이름

**블랙홀**: 내 정보가 모두 빨려 들어가기 때문에. 말해둬 → Ya(야) → 블랙홀 순서로 이름이 바뀌었습니다.
