# 블랙홀 구현 계획 (확정본)

확정 2026-10-25. 제품 소유자 지시 「계획서를 확정하고 구현을 시작」. 구조 설명은 `design/architecture.html`, 화면 시안은 `design/calendar-glass/prototype-glass.html`(유리 테마)·`prototype-doc.html`(공문서 테마), 리서치는 `design/calendar-glass/research.md`.

## 목표

휴대폰·데스크톱·메신저 어디서든 문장·음성·사진·파일을 **던져 두기만 하면** 이 Mac의 로컬 AI가 일정·할 일(하위 체크리스트·마감·알림)·기간·기억으로 정리한다. 정해진 시각에는 전화처럼 울리는 알람이 뜬다. 원본과 읽어 낸 글은 구글 드라이브의 「블랙홀」 폴더에 모여 옵시디언으로 검색된다.

## 확정된 결정

| 항목 | 결정 |
|---|---|
| 이름 | 블랙홀 (아이콘: 검은 판 위 일식 모양) |
| 테마 | 반투명 유리 / 공문서 보고서(개조식) 두 가지, 설정에서 선택. 출력(A4)은 공문서 양식 |
| 분석 | 이 Mac의 로컬 모델만(whisper.cpp, kordoc, Gemma 4 E2B/E4B). 외부 AI API는 보류 |
| 보관 | 구글 드라이브 `개인 계정`의 `블랙홀/` 폴더: `인박스/`, `원본/연/월/`, `노트/` |
| 검색 | `블랙홀/` 폴더를 옵시디언 보관함으로 열어 검색 (SecondBrain은 건드리지 않음) |
| 일간 화면 | 10분 칸(한 시간 한 줄·가로 6칸) + 할 일 체크리스트(□ 할 일 / ○ 하위 / - 마감·알림) |
| 입력 | 입력칸 항상 열림, 끌어 올리면 대화 기록, 아이콘(사진·말하기·넣기), 잠금화면에서도 보내기 |
| 알림 | 팝업이 아니라 전화처럼 전체 화면 + 반복 소리·진동, 「확인/완료/10분 뒤」 |
| 기록 형식 | 23열 Items 유지. 하위 할 일·추가 알림은 별도 표로 itemId 연결, 기간은 여러 날 종일 일정 |

### 기본값으로 정한 것 (사용자가 다르게 말하면 바꿈)

- **학교/개인 구분**: 같은 `블랙홀/노트/` 안에서 `학교/`, `개인/` 폴더로 나눈다. 학교 자료를 개인 구글 계정에 두는 것이 학교 지침상 괜찮은지는 사용자가 확인한다.
- **확정 방식**: 일정은 모두 「가승인」으로 넣고 확정/취소를 받는다(2026-10-24 결정 유지). 할 일·기간·기억은 바로 넣고 「되돌리기」를 준다.
- **원본 처리**: 인박스 원본은 지우거나 옮기지 않고 `원본/`에 사본을 남긴다. 같은 원본은 해시로 한 번만 처리한다.

## 단계

| # | 내용 | 바깥에 생기는 변화 | 완료 기준 |
|---|---|---|---|
| 1 | **작업기 확장** (지금): 하위 할 일·알림·기간 추출, 인박스 처리, 옵시디언 원본 노트, `블랙홀/` 폴더 구조 | 없음(시험 폴더). 실제 드라이브 폴더 만들기는 승인 후 | 시험 폴더에 파일을 넣으면 노트가 생기고 검색 가능, 단위 테스트, 필수 검사 통과 |
| 2 | **데스크톱 블랙홀 앱**(Mac, Tauri): 월·주·일, 두 테마, 입력·대화창, 출력, 데스크톱 알람, 작업기 연결 | Mac 앱 실행(설치는 승인 후) | 시안과 같은 화면이 실제 데이터로 동작, 알람이 울림 |
| 3 | **휴대폰 보내기**(안드로이드): 채팅 화면, 공유 메뉴 「블랙홀로 보내기」, 잠금화면 고정 입력 알림, 드라이브 인박스 업로드, 전체 화면 알람 | 휴대폰 설치는 승인 후 | 잠금 상태에서 보낸 것이 Mac에서 처리되어 돌아옴, 알람이 잠금 위에서 울림 |
| 4 | **가승인 캘린더 + 확정 루프** | 시험 캘린더만, 운영은 승인 후 | 가승인→확정/취소 왕복, 본 캘린더 불변 증명 |
| 5 | **위젯·잠금화면 배경, 디스코드·슬랙** | 시험 서버만 | 위젯·배경 갱신, 메신저 입력이 같은 대화로 들어옴 |
| 6 | **실제 자료로 정확도 재기**, 개인 단어 목록, 고친 내용 학습 | 없음 | 실제 정답률 표 |

## 승인이 필요한 행동

- 구글 드라이브에 `블랙홀/` 폴더 실제로 만들기·쓰기 (1단계 끝)
- 휴대폰 설치, 운영 캘린더 쓰기, 디스코드·슬랙 실제 서버 연결
- 작업 브랜치 push·병합

## 1단계 세부 (지금 진행)

1. 제안 JSON v2: 항목에 `subtasks`(하위 할 일), `reminders`(알림 시각 목록), 기간(`kind: PERIOD`, 여러 날)을 추가. 모델은 원문 표현만 옮기고 날짜·시각은 코드가 계산.
2. 인박스 처리기: `블랙홀/인박스/`의 새 파일 → 해시 → `원본/연/월/`에 사본 → 분석 → 노트. 같은 해시는 건너뜀. 실패는 대기열에 남아 다시 시도.
3. 옵시디언 원본 노트: `노트/{학교|개인}/연/월/날짜 제목 (해시8).md` — 머리말(해시·받은 시각·출처·상태), □/○ 체크리스트, 원문 전체, 원본 링크.
4. CLI: `blackhole-worker inbox --root 블랙홀폴더 [--once]`.
5. 검사: 단위 테스트(형식, 중복, 실패 후 재시도, 노트 내용), 필수 검사.
