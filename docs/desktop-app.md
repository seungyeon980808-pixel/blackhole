# 블랙홀 데스크톱 앱 (Mac)

Tauri 2 + TypeScript. 같은 달력 화면(`desktop/src/calendar/`)을 휴대폰 앱이 WebView로 띄웁니다.

## 실행

```sh
cd desktop
npm ci
npm run tauri dev                         # 개발 실행
npm run tauri build -- --bundles app      # src-tauri/target/release/bundle/macos/Blackhole.app
```

- 서명·공증은 하지 않습니다. 만든 앱으로 `/Applications/Blackhole.app`을 교체합니다(덮기 전에 `~/.local/share/blackhole/app-backup/`에 복사).
- AI 다듬기는 Claude Haiku 5.5 API(키는 키체인, `docs/local-worker.md`). 키가 없거나 예산을 넘으면 초안만 넣습니다. 로컬 모델(Ollama)은 `"analyzer": "local"`일 때만 씁니다.
- 브라우저(`npm run dev` → http://127.0.0.1:1420)로 열면 「미리보기·미연결」 모드: 작업기·인박스 없이 화면만 봅니다.

## 저장 위치 (로컬·미연결)

`~/Library/Application Support/com.malhaedwo.blackhole.desktop/`

| 파일·폴더 | 내용 |
|---|---|
| `blackhole-calendar-v1.json` | 일정·할 일·기간·기억·대화·설정. 원자적 저장. 깨진 파일은 `.corrupt-<시각>`으로 옮겨 두고 새로 시작 |
| `입력/<해시8>-<이름>` | 앱에서 보낸 사진·녹음·파일의 사본(작업기가 읽는 원본) |
| `시험-블랙홀/` | 인박스 시험 폴더(`인박스/`, `원본/`, `노트/`, `.블랙홀/`). 설정에서 「인박스 처리」를 켜면 15초마다 훑음 |

구글 캘린더·시트에는 아무것도 쓰지 않습니다. 인박스 폴더는 설정에서 「시험 폴더」와 「드라이브 「블랙홀」」 중 고릅니다(기본은 시험 폴더). 드라이브 폴더는 휴대폰이 만든 `~/Library/CloudStorage/GoogleDrive-*/내 드라이브/블랙홀`만 허용하고, 거기에는 `원본/` 사본과 `노트/`·`.블랙홀/`만 씁니다. 인박스 원본은 지우거나 옮기지 않습니다. 그 밖의 동기화 폴더(iCloud, Dropbox, 드라이브의 다른 폴더)는 거부합니다.

## 쓰는 법

- 오른쪽 대화 패널에 쓰고 Enter: 넣을 말이면 달력에(초안 → AI가 다듬음), 질문이면 내 기록에서 답합니다(「치과 언제야?」, 「이번 주 마감 뭐 있어?」, 「학교 와이파이 비번 뭐였지?」). 결과와 답은 대화 안 카드에서 확정·완료·수정·열기·복사. 패널은 「접기」/머리줄 「대화」/⌘L로 접고 펴며, 왼쪽 가장자리를 끌어 폭을 바꿉니다.

- 아래 입력칸에 문장을 쓰고 Enter(또는 ↑). 사진 단추는 사진·PDF·한글·워드·엑셀·txt·wav를 받습니다. 마이크 단추는 누르면 녹음, 다시 누르면 보냅니다. 창에 파일을 끌어 놓아도 됩니다.
- 일정은 「가승인」(점선, 「가」)으로 들어갑니다. 확정/취소는 입력칸 위 한 줄, 대화 기록, 일간 「확인 대기」에서. 할 일·기간·기억은 바로 들어가고 「되돌리기」가 있습니다.
- 손잡이를 끌어 올리면(또는 누르면) 대화 기록이 열립니다.
- 알람: 정해진 시각에 창이 맨 앞으로 오고(항상 위), Dock이 튀고, 「Glass」 소리가 반복됩니다. 「확인/완료」 또는 「10분 뒤」를 누를 때까지(최대 10분) 계속됩니다. 창을 닫아도 앱은 Dock에 남아 알람을 울립니다(완전히 끄려면 ⌘Q).
- 출력: 지금 보기(월·주·일)를 A4 공문서 양식으로 미리 보고 「인쇄」.
- 유리 테마는 창이 반투명이라 바탕화면이 흐리게 비칩니다(2026-10-25 제품 소유자 요청). 공문서 테마는 불투명한 흰 종이입니다.
- 설정: 유리/공문서, 어둡게/밝게, 가짜 자료 보이기, 인박스 처리, 알람 시험(10초 뒤).

## 어댑터 (휴대폰이 구현할 것)

`desktop/src/calendar/adapter.ts`의 `BlackholeAdapter`: `load/save`, `analyze`, `inboxStatus/setInbox/inboxResults`, `scheduleAlarms/onAlarm/ring`, `print`, (선택) `onFileDrop`. 휴대폰은 같은 화면에 자기 어댑터를 넘기면 됩니다.

## 휴대폰과 달력 공유 (2026-10-25)

- 휴대폰 블랙홀 앱이 같은 달력 화면(`desktop/src/calendar/`)을 WebView로 띄웁니다. 웹 묶음은 `npm run build:phone` → `desktop/dist-phone/`(Git에 넣지 않음), APK를 만들 때 `assets/calendar/`로 들어갑니다.
- 휴대폰의 구글 권한(drive.file)은 자기가 만든 파일만 보므로, **휴대폰이 드라이브 「블랙홀/달력.json」을 빈 파일로 먼저 만들고** Mac 앱은 그 파일에 덮어쓰기만 합니다(새로 만들지 않음).
- Mac: 설정 「휴대폰과 달력 공유」를 켜면 저장할 때마다 일정·할 일·기간·기억 사본을 씁니다(대화·접수 기록은 넣지 않음). 학교 일정 제목이 개인 구글 드라이브에 올라갑니다(제품 소유자 선택, 2026-10-25).
- 휴대폰: 사본을 받아 보여 주고, 입력은 「블랙홀/인박스/」로 보냅니다(Mac이 분석). 휴대폰에서 누른 확정·취소·체크·하위 추가·알람 응답은 `인박스/*.bhact` 작은 파일로 보내고, Mac 앱이 읽어 한 번만 반영합니다(파일은 지우지 않음, 작업기는 건너뜀). 알람은 휴대폰의 전화식 알람이 울립니다.

## 디스코드·슬랙 입력 (5단계, 2026-10-25)

- 지정한 채널에서 **내 메시지만** 30초마다 가져와 인박스에 넣습니다(문장은 `.txt`, 첨부는 그대로). 처음 켤 때는 지난 대화를 가져오지 않습니다. 디스코드·슬랙에는 아무것도 쓰거나 지우지 않습니다.
- 설정 파일(저장소 밖): `~/.config/blackhole/messenger.json` — 형식은 `tools/messenger.example.json`. 둘 중 하나만 써도 됩니다. `allowedUserId`(내 사용자 ID)는 꼭 넣습니다.
  - 디스코드: 개발자 포털에서 봇을 만들고 「Message Content Intent」를 켠 뒤 봇 토큰, 채널 ID, 내 사용자 ID를 적습니다. 봇을 그 채널에 초대합니다.
  - 슬랙: 앱을 만들어 `channels:history`(비공개 채널이면 `groups:history`), `files:read` 권한을 주고 봇 토큰(`xoxb-`), 채널 ID, 내 사용자 ID를 적습니다. 봇을 채널에 초대합니다.
- Mac 앱 설정의 「디스코드·슬랙 입력」을 켭니다(인박스 처리도 켜져 있어야 분석됨). CLI: `blackhole-worker messenger --root <블랙홀 폴더> --watch 30`.
- 결과 회신(「넣었어요」 답장)은 아직 없습니다. 결과는 Mac·휴대폰 달력과 대화 기록에서 봅니다.
