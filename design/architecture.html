Ya 전체 구조 설계 (초안)

2026-10-25 · 목표: 휴대폰·데스크톱·메신저 어디서든 던져 두기만 하면 일정·할 일·기억으로 정리되고, 원본은 옵시디언에서 검색된다. 분석은 이 Mac의 로컬 AI만 쓴다.

한 줄 요약
모든 입력은 하나의 인박스로 모이고, Mac의 작업기가 하나씩 꺼내 읽고(글로 바꾸고) → 뽑고(일정·할 일·기억) → 나눠 보냅니다(캘린더 / 할 일 목록 / 옵시디언). 원본은 절대 지우지 않고, 어디서 왔는지 끝까지 연결됩니다.

1. 전체 흐름

① 던지는 곳
휴대폰 · 잠금화면고정 알림의 [말하기][적기][사진], 볼륨 버튼 녹음(이미 있음), 빠른 설정 타일
휴대폰 · 앱/공유카톡형 채팅, 갤러리·카톡·파일 앱에서 「Ya로 보내기」, 홈 위젯
데스크톱채팅 칸, 파일 끌어놓기, 단축키 빠른 입력, 넣기 폴더

로컬 인박스 + 대기열원본 사본을 해시로 보관 → 받음/분석 중/결과 있음/실패. 같은 원본은 한 번만

③ 나눠 보내는 곳

흐름이 한 방향이라 어느 입구로 들어와도 처리 방법이 같습니다. 새 입구(예: 이메일)를 붙일 때도 「인박스에 넣기」만 만들면 됩니다.

2. 잠금화면에서 바로 보내기 — 가능합니다

방법잠금 해제 없이내용
볼륨 버튼 녹음됨 (이미 있음)화면이 꺼져 있어도 길게 눌러 말하기. 지금 Ya 0.9.0 기능
고정 알림 「Ya에게 보내기」됨잠금화면 알림에 [🎤 말하기] [⌨ 적기] [📷 사진]. 「적기」는 알림 안에서 바로 입력(바로 답장 방식)
잠금화면 위 촬영·녹음 화면됨카메라 앱처럼 잠금 위에 뜨는 작은 화면에서 찍거나 말하고 보냄. 빠른 설정 타일·잠금화면 바로가기(삼성)로 엶
갤러리에 있던 사진 고르기안 됨보안상 잠금을 풀어야 갤러리를 볼 수 있음. 「Ya로 보내기」 공유는 잠금 해제 후
잠금화면에서 일정 보기됨달력을 그린 배경화면을 자동으로 바꿔 넣는 방식 + 알림. 학교 일정 제목 가리기 옵션 필수(학생 이름 노출 방지)
잠금화면 입력은 휴대폰을 든 누구나 「추가」는 할 수 있다는 뜻입니다. 대신 잠금 상태에서는 보내기만 되고, 지난 기록·다른 일정 내용은 보이지 않게 합니다. 잘못 들어온 건 가승인 단계에서 취소하면 됩니다.

3. 파일 → 인박스 → 옵시디언 (검색용)

  1. 받기: 원본을 드라이브 「Ya 인박스」(휴대폰) 또는 Mac 넣기 폴더(데스크톱)로. Mac 작업기가 로컬 인박스로 가져와 SHA-256으로 보관.
  2. 읽기: kordoc이 PDF·한글·워드·엑셀·사진을 글(마크다운)로, whisper가 음성을 글로.
  3. 옵시디언 원본 노트 만들기: Ya/2026/10/2026-10-25 가정통신문 현장체험학습 (a1b2c3d4).md
    • 머리말: 받은 시각, 어디서 왔는지(휴대폰 사진·디스코드 등), 원본 해시, 개인/학교 구분, 상태(미확정)
    • 본문: 읽어 낸 전체 글(검색 대상) + 원본 파일 링크(Ya/첨부/에 사본)
    • 연결: 이 원본에서 나온 일정·할 일 목록과 링크, 같은 날 다른 입력 링크
  4. 검색: 옵시디언 검색으로 「현장체험학습」, 「동의서」 같은 낱말을 찾으면 원본 노트가 나오고, 거기서 원본 파일·일정으로 이어집니다.
SecondBrain 규칙과 맞추기: 지금 보관함은 개인 자료만 받고, 업무 자료는 별도 보관함이 정해질 때까지 넣지 않는 규칙이 있습니다. 또 위키(wiki/)는 확인된 사실만 두는 곳이라, Ya는 위키를 고치지 않고 Ya/ 폴더에 원본 노트만 씁니다. 학교 자료는 별도 「학교 보관함」을 만드는 것을 권합니다. (결정 필요)

4. 할 일 체크리스트

  • 할 일은 이미 Ya 기록(23열 시트)에 kind = TODO로 있고, 완료는 status = DONE입니다. 새 칸 없이 체크리스트를 만들 수 있습니다.
  • 보이는 곳: 데스크톱 일간 보기, 휴대폰 일 보기, 홈 위젯, 잠금화면 달력판. 어디서 체크해도 같은 기록이 완료됩니다.
  • 마감이 있는 할 일(예: 「11월 4일까지 동의서 제출」)은 그날 체크리스트에, 마감 없는 할 일은 「언젠가」 묶음에.
  • 할 일마다 출처 링크: 눌러서 원본 공문·음성으로 바로 갑니다.

4-1. 할 일 구조: 마감 · 하위 체크리스트 · 기간 · 알림 (2026-10-25 추가)

개념예기록 방법
할 일 + 마감연수 보고서 제출, 10/30 18:00까지 (D-5)Ya 기록 TODO, startAt=마감 시각
하위 체크리스트자료 정리 / 소감 작성 / 결재 올리기23열에 칸이 없음 → 하위 항목 표(itemId·순서·제목·완료)를 따로 두고 부모 itemId로 연결. 옵시디언 원본 노트에도 체크박스로 기록
기간수행평가 채점 기간 10/19–10/30SCHEDULE의 startAt~endAt이 여러 날(종일). 캘린더에는 종일 여러 날 일정
알림15:00 「30분 뒤 안과 진료」, 10/29 09:00 「보고서 마감 하루 전」reminderAt(첫 알림) + 추가 알림은 하위 표와 같은 방식. 휴대폰은 정확한 시각 알람(이미 있는 ReminderScheduler), 데스크톱은 OS 알림

말로도 넣을 수 있게 합니다: 「금요일 6시까지 보고서 제출: 자료 정리, 초안, 결재, 목요일 9시에 알려줘」 → 할 일 1 + 하위 3 + 알림 1. 「11월 16일부터 20일까지 기말고사 출제 기간」 → 기간 1. 로컬 작업기의 제안 JSON에 subs, reminders, 여러 날 기간을 추가해야 합니다(아직 미구현).

4-2. 알람: 전화 오는 것처럼 (2026-10-25 추가)

정해진 시각이 되면 팝업이 아니라 화면 전체를 덮는 알람이 뜨고, 「확인·완료·10분 뒤」를 누를 때까지 소리와 진동이 계속됩니다.

기기만드는 방법주의
안드로이드정확한 시각 알람(setAlarmClock, 기존 앱에 정확한 알람 권한 있음) → 잠금 위에 뜨고 화면을 켜는 알람 화면(전체 화면 알림) → 알람 음량으로 반복 소리 + 반복 진동안드로이드 14부터 「전체 화면 알림」은 설정에서 허용해야 함(삼성: 앱 → 알림 → 전체 화면 알림). 알람 음량은 무음·진동 모드에서도 울림. 실제 기기에서 소리·진동·잠금 위 표시는 아직 검증 안 됨
데스크톱항상 위에 뜨는 알람 창 + 반복 소리, 다른 창 위로 올라옴Mac 「집중 모드」 중에도 보이게 하려면 블랙홀을 허용 앱으로 넣어야 함

입력칸을 위로 끌면 큰 대화창(대화 기록)이 열립니다. 휴대폰·데스크톱·디스코드에서 보낸 것이 한 대화로 모이고, 각 결과에 확정·취소·되돌리기가 붙습니다.

5. 데스크톱 일간 보기 — 「업무관리판」 방식, 가능합니다

  • 시간 줄: 하루를 3시간짜리 가로 줄로 나눕니다(7–10시, 10–13시 …). 일정 칸이 왼쪽에서 오른쪽으로 시간만큼 이어지고, 시간이 넘어가면 다음 줄로 이어집니다. 빈 시간이 세로로 길게 남지 않습니다.
  • 오늘 할 일 판: 「할 일 · 하는 중 · 끝」 세 칸(또는 체크리스트). 마감·출처·학교/개인 표시.
  • 오늘 들어온 것: 오늘 인박스에 들어온 원본과 분석 상태(분석 중/완료/검토 필요), 옵시디언 원본 노트 바로가기.

시안(prototype.html)의 데스크톱 「일」 보기에 이 방식으로 넣었습니다.

7. 보안 경계

  • AI 분석은 Mac 로컬에서만. 외부 AI API는 보류(결정됨).
  • 구글 드라이브는 보관만 합니다(지금 음성 원본과 같음). 학교 자료를 개인 구글 계정에 두는 것이 괜찮은지는 학교 지침 확인이 필요합니다. 원하면 휴대폰 → Mac 직접 전송(같은 와이파이)도 가능하지만, Mac이 꺼져 있으면 기다려야 합니다.
  • 잠금화면·위젯: 학교 일정 제목 가리기, 잠금 상태에서는 보내기만.
  • 디스코드·슬랙: 내 계정에서 온 메시지만 받기, 봇이 받은 원본도 같은 인박스 규칙.

8. 만드는 순서 (제안)

  1. 로컬 작업기 핵심 끝남
    음성·문서·사진 → 제안 JSON, 대기열, 평가
  2. Mac 인박스 + 옵시디언 원본 노트 다음
    넣기 폴더에 파일을 넣으면 옵시디언에 검색되는 노트가 생김. 구글 연결 없이 바로 써 볼 수 있음
  3. 휴대폰 보내기 새로
    카톡형 채팅, 「Ya로 보내기」 공유, 잠금화면 알림 입력·촬영, 드라이브 인박스 업로드
  4. 가승인 캘린더 + 할 일 체크리스트 + 확정 알림
    원래 계획의 3단계에 체크리스트 추가
  5. 새 캘린더 화면
    데스크톱(월·주·업무관리판 일간·채팅), 안드로이드 위젯, 잠금화면 배경
  6. 디스코드·슬랙 뒤

원래 5단계 계획(맥판·구글 읽기 → 가승인 → 링크 → 메신저)과 순서가 달라집니다. 2번을 먼저 하면 구글 연결 없이 「파일 넣으면 옵시디언에서 검색」을 가장 빨리 쓸 수 있습니다.

9. 정해 주실 것

  1. 학교 자료용 옵시디언 보관함을 따로 만들지 (권장), SecondBrain 규칙을 바꿀지
  2. 결정됨 (2026-10-25): 휴대폰 → Mac 전달과 보관은 구글 드라이브 개인 계정 계정의 「블랙홀」 폴더(인박스·원본·노트). 이름은 「블랙홀」.
  3. 확정 방식: 전부 가승인 → 확인 / 확실한 건 바로 확정, 애매한 것만 물어보기
  4. 만드는 순서: 위 제안대로 2번(인박스 + 옵시디언)부터 할지
